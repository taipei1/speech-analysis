# Speech Analysis Project

This repository contains the source code used for calculations, linguistic analysis, data visualization, and comparative studies presented in the following project:

**Presentation:** [Mníchovský prejav - Finálna Verzia](https://docs.google.com/presentation/d/1vPra6AtC_fIBwMl1siCeO445HY9YBfm2bRMWFtOIzqE/edit?usp=sharing)

## Overview
The code implements a methodology for analyzing political discourse, focusing on:
- **Quantitative Metrics:** Deictic indices, modal profiles, and speech act distribution.
- **Visualizations:** Graphs and charts generated via Matplotlib and Pandas.
- **Comparative Analysis:** Tools for contrasting different segments of the 2007 Munich Security Conference speech.

## Requirements
- Python 3.x
- Pandas
- NumPy
- Matplotlib

## Usage
1. Clone the repository.
2. Install dependencies.
3. Run the analysis scripts to reproduce the results shown in the presentation.
